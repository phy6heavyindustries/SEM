## What is SEM?

**Salt Electro Mining** is an open-source, closed-loop system that uses:
- **Input**: Salt + water + electricity + metal-bearing material
- **Process**: Chlorine-based leaching generated in situ from membrane electrolysis
- **Output**: Pure precious metals + fertilizer byproduct
- **Recovery**: ~99% for extractable metals
- **Cost**: Chemically self-sufficient (no purchased reagents)

## Key Capabilities

| Extractable | Examples |
|-------------|----------|
| Precious Metals | Gold, silver, platinum, palladium, rhodium, iridium |
| Rare Earth Elements | All lanthanides |
| Critical Minerals | 25/25 US critical minerals |
| Heavy Metals | Lead, copper, iron, toxic metals |

## Safety Warning

⚠️ **SEM involves real hazards**: toxic chlorine gas, explosive hydrogen, corrosive acids. Read [safety.md](docs/safety.md) before any experimentation.
