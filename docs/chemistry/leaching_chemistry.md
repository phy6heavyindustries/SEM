# Leaching Chemistry

## The Chlorine-Based Leaching System

### Chemistry Overview
The system uses **chlorine** as the primary oxidizing agent, generated in situ from saltwater:

1. **Source**: NaCl (ordinary salt) + H₂O (water)
2. **Process**: Membrane electrolysis
3. **Products**: Cl₂ (chlorine) + HCl (hydrochloric acid)
4. **Environment**: pH ~0, ORP > 1.5V

### Exceptions (not dissolved in single step)

- Graphite
- Silicon
- Titanium
- Tungsten

## Process Control

### Key Parameters
- pH: ~0 (highly acidic)
- ORP: 1.5V+ (strongly oxidizing)
- Temperature: Works below freezing
- Electrode configuration: Adjustable

### Metal Recovery
- Selective precipitation possible
- Electrodeposition from solution
- Different plating voltages for different metals
