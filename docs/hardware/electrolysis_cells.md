# Electrolysis Cells

## Construction

### Materials
- **Primary**: PVC or CPVC piping/sheets
- **Adhesive**: PVC cement (CPVC cement for CPVC)
- **Solvents**: Tetrahydrofuran, cyclohexanone (optional for cleaning)

### Construction Techniques

#### Glue Application
- **Use**: Disposable syringe (not whole can of PVC glue)
- **Advantage**: Precise amount, consistent application, minimal waste
- **Process**: Suck PVC cement into syringe, squirting exact amount needed

#### Build Types
1. **Quick prototype** - Fast assembly for testing
2. **Modular serviceable** - Built for easy component replacement

### Design Configurations
- Multiple electrode arrangements (2+ positive, 1+ negative)
- Adjustable electrode spacing (affects voltage/current characteristics)
- Membrane installation between compartments
- Input/output ports for solution flow

### Applications
- SEM leaching
- Redox flow batteries
- Acid production
- Metal refining

### Operating Parameters
- Voltage: 12V typical
- Current: 17A typical
- Electrode spacing affects power characteristics
- Multiple electrode configurations possible

## Safety
- Watch safety videos before building
- Not for blind experimentation
- Proper chemical handling required
- Ventilation essential

## Troubleshooting

| Issue | Cause | Solution |
|-------|-------|----------|
| Voltage drops | Increased electrode spacing | Adjust electrode positioning |
| Dendrite shorts | Metal plating through membrane | Reduce current density, increase membrane thickness |
| Leaking joints | Insufficient glue | Use syringe for precise application |
