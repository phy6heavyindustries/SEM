# Equipment Overview

## Core System Components

### 1. Electrolysis Cell System
- Construction: PVC/CPVC for chemical resistance
- Design: From quick prototypes to modular, serviceable builds
- Syringe application for precise PVC glue
- Redox flow battery compatible

### 2. Ion Exchange Membrane System
- DIY production, < $1/sq yard
- Cation and anion variants
- Public domain - no patents
- Replaceable (low cost enables easy replacement)

### 3. Power System
- DC power supply
- 12V operating voltage
- High current capability (17A+)
- Scalable to 2KW+ per unit

### 4. Analysis Equipment

#### XRF Spectrometer
- **Recommended**: Rigaku NEX DE
- Purpose: Ore analysis, PGM detection, process verification
- Warning: Mayzum MAY-72XRF is confirmed scam ($17K loss)
- Important: XRF is screening tool, not quantitative assay

#### Stannous Chloride Test
- Purpose: Gold detection verification
- Works on ore and e-waste
- Low-cost supplement to XRF
- Essential before processing

### 5. Workshop/Lab Infrastructure
- Chemical-resistant epoxy flooring
- Spray foam insulation for temperature control
- Composite workbench materials
- Chemical storage cabinets
- Ventilation system

### 6. XRF - Common Mistakes
- Don't use XRF as quantitative assay
- Handheld XRF has limitations
- Physical metal recovery = ultimate proof
- Use multiple verification methods
