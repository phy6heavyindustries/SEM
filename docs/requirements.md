# SEM System Requirements

## Equipment Requirements

### Essential Equipment

| Item | Purpose | Notes |
|------|---------|-------|
| Electrolysis Cell | Core processing unit | See [Electrolysis Cells](hardware/electrolysis_cells.md) |
| Ion Exchange Membrane | Compartment separation | DIY, < $1/sq yard, [Membrane Guide](hardware/membranes.md) |
| Power Supply | DC for electrolysis | 12V, high current capability (17A+) |
| Ventilation System | Gas management | Critical for chlorine and hydrogen |
| XRF Analyzer | Ore analysis and verification | Rigaku NEX DE recommended |
| Stannous Chloride Kit | Gold testing verification | Low-cost, essential supplement to XRF |
| Chemical Storage | Safe reagent handling | Acid-resistant containers |
| PPE | Personal protection | See [Safety](safety.md) |

### Electrolysis Cell Specifications

| Parameter | Value |
|-----------|-------|
| Construction Material | PVC or CPVC (chemical resistant) |
| Membrane Type | DIY ion exchange (cation or anion) |
| Operating Voltage | 12V |
| Operating Current | 17A |
| Power Capacity | 2KW+ units |
| Theoretical Throughput | 1 ton ore per unit |

### Facility Requirements

The SEM laboratory requires:
- Chemical-resistant flooring (epoxy recommended)
- Insulation for temperature control (spray foam mentioned)
- Chemical storage cabinets
- Proper ventilation throughout
- Electrical infrastructure for high-current operation
- Emergency response equipment

## Material Requirements

### For Membrane Production
- PVC or CPVC cement
- Ion exchange resin (water softener resin for cation)
- Solvent: tetrahydrofuran or cyclohexanone
- Ball mill or high-speed grinder for resin processing

### For Operation
- Salt (NaCl, seawater salt acceptable)
- Water
- Feedstock (ore, e-waste, tailings)
- Replacement membranes (DIY, low cost)
